SUPERMARKET SALES DATASET
=========================

1. Dataset Overview
-------------------

The Supermarket Sales dataset contains transaction-level sales information used to analyze supermarket business performance.

The dataset contains 10,000 transaction records and 28 columns.

The data covers transactions from June 2024 to June 2025.

The dataset is used to analyze revenue, profit, costs, products, product categories, customers, cities, countries, discounts, and sales trends over time.


2. Dataset Purpose
------------------

The purpose of this dataset is to support business and sales analysis.

It can be used to answer questions such as:

- What is the total revenue?
- What is the total profit?
- Which products generate the most revenue?
- Which product categories generate the most revenue?
- Which cities generate the most revenue?
- Which customer type generates the most revenue?
- Which product categories have the highest profit margins?
- Which months have the highest or lowest revenue?
- How are revenue and profit related?


3. Dataset Structure
--------------------

The dataset contains transaction-level information.

Each row represents a sales transaction.

The dataset includes information about:

- Transaction date
- Geographic location
- Customer information
- Gender
- Product category
- Product
- SKU(Stock keeping unit )
- Unit cost
- Sales price
- Quantity
- Revenue
- Profit
- COGS(Cost of goods sold)
- Discount
- Other calculated and supporting fields


4. Data Storage
---------------

The cleaned dataset is available as a CSV file and is also stored in SQL Server for analytical queries.

The SQL Server database used for the project is:

supermarketAI

The main SQL table is:

dbo.SupermarketSales


5. Data Validation
------------------

The SQL database was validated to confirm that the SupermarketSales table contains 10,000 records.

The Python dataset was also loaded successfully and confirmed to contain:

Rows: 10,000
Columns: 28

The Date column was converted to a datetime data type.

The Revenue column was converted to a numeric data type.

There were no missing values in the Date column.

There were no missing values in the Revenue column.


6. Important Analytical Values
-------------------------------

The total recorded revenue in the dataset is approximately:

206.21 million

The total recorded profit is approximately:

43.84 million

Profit was validated against the formula:

Profit = Revenue - COGS(Cost of goods sold)

The validation showed that all 10,000 records matched this relationship.

8. Important Data Note
----------------------

Revenue should be treated as the recorded Revenue field in the dataset.

Revenue does not consistently equal:

Sales Price × Quantity

Therefore, the recorded Revenue column should be used when answering questions about recorded revenue unless a different calculation is explicitly requested.

Profit was validated separately and is consistent with:

Profit = Revenue - COGS
