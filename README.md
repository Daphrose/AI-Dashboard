# E-Commerce Experiment & Customer Analytics

## Project Overview

This project investigates whether a new e-commerce checkout experience
improves customer conversion and purchasing behavior.

The project combines data analysis, statistics, experimentation,
and eventually data engineering.

## Main Research Question

Does the new checkout experience lead to a higher conversion rate
than the existing checkout experience?

## Objectives

- Explore customer and transaction data
- Understand the distribution of key variables
- Apply descriptive statistics
- Study probability and sampling
- Perform hypothesis testing
- Conduct an A/B test
- Measure the effect of the new checkout experience
- Build a data pipeline for processing the data
- Store analytical data in a database
- Present the final findings
